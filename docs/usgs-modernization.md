Approved daily-mean normals for Nov 26 returned median 961.5 cfs (74 samples) at Au Sable, 163 cfs (54 samples) at Black River. Legacy RDB Au Sable median was 962 cfs (rounded). These are recorded source examples, not current readings. Both modern endpoints support batching; live data is filtered by station, parameter and units, source timestamp and age. Historical comparison uses approved daily means, not instantaneous values. Missing data or malformed/paginated payloads fail soft. The existing HTML source budget stays four seconds. No paid service or private storage added. Production runtime availability and rate limits remain to be verified.
